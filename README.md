## 📌 About

I engineer scalable backend services, resilient distributed architectures, and native cross-platform client applications. My work spans high-throughput APIs, local-first reactive mobile pipelines, and on-device machine learning experiences.

- 🔭 **Core Work**: Architecting **[Bintrayx.store](https://bintrayx.store)** — desktop/mobile software marketplace with modular licensing and telemetry.
- 📱 **Mobile & ML**: Shipped multiple production consumer apps to Google Play including **[Aurum Visage](https://play.google.com/store/apps/details?id=com.spicarr.aurumvisage)** (on-device computer vision), **[Tacto](https://play.google.com/store/apps/details?id=com.spicarr.tacto&hl=en_IN)** (heuristic AI board game), and **[Lovio](https://play.google.com/store/apps/details?id=com.spicarr.lovio.lovio)** (Riverpod + Hive offline-first architecture).
- ⚙️ **Backend Specialization**: Designing asynchronous REST & WebSocket systems with **FastAPI**, **Django REST Framework**, and **Go (Gin)** backed by PostgreSQL & Redis.
- 🎥 **Technical Education**: Sharing algorithmic problem-solving, clean code mechanics, and systems design on **[Spicarr Coding](https://www.youtube.com/@spicarrcoding)**.
